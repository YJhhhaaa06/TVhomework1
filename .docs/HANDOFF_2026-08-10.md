### 3.3 编码与 Maven 调用（本会话最隐蔽的坑）

- Python 在管道/重定向下 stdout 用 GBK（中文系统 cp936）；本环境 PowerShell 7 的 `[Console]::OutputEncoding` 是 UTF-8。
- **`*>` 重定向会把 Python 的 GBK 字节按 UTF-8 解码，中文变成 U+FFFD（EF BF BD），日志永久损坏**；普通 `>` 会透传原始字节（GBK 完好）。读 GBK 日志用 `Get-Content -Encoding oem`（PS7 默认 UTF-8 会乱码）。
- run_tests.py 在 **Maven 失败**后打印错误输出时会因 stdout GBK 编码崩溃（`UnicodeEncodeError`），导致真正的编译错误看不到。对策：用 Python subprocess 原样复刻 Maven 调用（`-o -q package -DskipTests -Duser.home=C:\Users\ASUS -Dmaven.repo.local=D:\dev\WorkSpace\VideoPlatform\maven`，JAVA_HOME 指向 `D:\dev\DevTools\jdk\openjdk-25.0.2`），把 stdout/stderr 写 UTF-8 文件再读。
- **PowerShell 直接调 `mvn.cmd` 时 `-D` 参数会失效**（Maven 读不到，落到 `C:\.m2\repository` 报 Access denied）。必须走 `python tools\run_tests.py build` 或 Python subprocess。这是阶段二/三排查过的确定结论。
- 跑测试前设 `$env:PYTHONIOENCODING='utf-8'` 可避免上述乱码。

### 3.4 代码与架构

- **HttpServlet 的 doGet/doPost 覆写不能声明 `throws Exception`**（只能 ServletException/IOException）。阶段三把服务层残留的受检异常（UserService.login/changePassword、LikeService）收口成 DatabaseException，控制器统一只声明 `ServletException, IOException`；UploadController 用 `ServletException` 包装非业务异常后抛出，由 ExceptionFilter 兜底。
- ErrorCode 从接口改枚举后，靠 `BusinessException(ErrorCode,...)` 与 `BaseServletUtil.writeError(ErrorCode,...)` 重载兼容旧调用点，基本不用逐个改。
- **注册重复手机号必须保持 401**（pytest E-02 断言 401；架构计划的 DuplicatePhoneException 是 409，用户决策：409 只用于改手机号场景）。不要改回 409。
- 登录"用户不存在"404→401、非法上传类型 500→400 是阶段三的有意修正（无测试断言）。
- web.xml 原本已注册 EncodingFilter，同时它还有 `@WebFilter` 注解（双注册隐患）；阶段三已去注解，并把 ExceptionFilter 放链首。**改 web.xml 时注意别重复加块**（本会话犯过一次，apply_patch 匹配到了已有块）。
- `/upload/*` 由 `context.xml` 的 PostResources 提供，不是 UploadServlet；AppShutDownListener 启动时校验 context.xml base 与 `app.properties` 的 `upload.path` 一致，不一致拒绝启动。改路径必须两处同步。
- 配置已外部化：MyConnectionPool/MyRedisPool/JwtUtil/FileUploadService/LogUtil/ContentService 都读 `AppConfig`；环境变量覆盖规则为"key 去点转大写"（`log.file` 另支持 `LOG_PATH` 别名）。
- **DAO 现在全部只接收 Connection**，连接/事务统一由 `TransactionTemplate`（@Component，注入）管理；新增 DAO 方法不要再自取连接。MediaAuditService.scanAll 已改为单事务。
- CountRepairTool 是唯一保留 printStackTrace/System.out 的 main 运维工具（计划允许），业务代码必须零 printStackTrace/System.out。
