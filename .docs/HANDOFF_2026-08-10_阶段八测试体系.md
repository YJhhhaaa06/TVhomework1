## 5. 本会话踩过的坑（新增）

- **test-compile 一直"通过"是假象**：CouponAdmin 不引用主类，从未真正读取 `target/classes`；任何引用主类的测试在沙箱内都会报"程序包 com.itheima.* 不存在"。已用 `-Dstage8.buildDir` 指向 D 盘解决。
- **mvn.cmd 调用方式**：Python subprocess 直接调 mvn.cmd 曾报 JAVA_HOME 错误 → 收口脚本用 `cmd /c call`；`run_tests.py` 原有直接调用方式已正常工作，勿改。
- **surefire 3.2.5 与 junit-bom**：JUnit 6.0.3 的 BOM import 会把 launcher 顶到 6.0.3（仓库没有）→ 全套统一 6.0.0 最稳，不要混 6.0.3。
- **pytest restore 无 multipart 时 getPart 抛 ServletException → 500**：测 400 分支必须发 multipart 表单字段（`files={"dummy": (None, "x")}`）。
- **Mockito 自挂载 + byte-buddy-agent 动态加载警告**：JDK 25 可运行；未来 JDK 若默认禁用动态 agent，需在 surefire argLine 加 `-javaagent` 指向 byte-buddy-agent 1.17.8。
- 工具层面：apply_patch 对重复上下文的多 hunk 可能错位/失败，小步单 hunk 更稳。
