## 一、项目概述

这是一个**仿短视频/内容社区平台**的 Java Web 学习项目，项目名为 `untitled`，groupId 为 `com.itheima`（黑马程序员）。

### 核心约束

记录在 `CLAUDE.md` 中：
- **禁止使用 Spring、Spring Boot、MyBatis**
- 所有框架均手工实现
- 日志等级标准：SEVERE / WARNING / INFO / FINE

### 技术架构

```
纯 Servlet + 手写 IoC 容器 + 原生 JDBC
数据库：MySQL（TVDatabase）
缓存：Redis
认证：JWT
```

## 五、包结构详解

### 5.1 ioc 包 — 手写 IoC 容器（266行）

实现了一个轻量级的依赖注入容器：

| 类 | 行数 | 功能 |
|----|------|------|
| IocContainer | 189 | 单例容器，实现类扫描、拓扑排序、依赖注入、生命周期管理 |
| ClassScanner | 47 | 递归扫描 classpath，找到所有 @Component 类 |
| @Component | - | 标记为受管 Bean |
| @Inject | - | 字段依赖注入 |
| @PostConstruct | - | 初始化后回调 |

**核心流程**：
1. ClassScanner 扫描 `com.itheima` 下所有带 `@Component` 注解的类
2. 拓扑排序解决依赖顺序（Kahn 算法，检测循环依赖）
3. 反射创建实例 + 字段注入
4. `@PostConstruct` 初始化回调
5. `shutdown()` 生命周期管理

## 六、数据库设计

### 6.1 连接配置

配置硬编码在 `MyConnectionPool.java` 中：
- **URL**: `jdbc:mysql://localhost:3306/TVDatabase?useSSL=false&serverTimezone=Asia/Shanghai`
- **用户名**: `root`

### 6.2 数据库表

项目中没有 SQL 文件，从 DAO 层 SQL 可推断存在以下表：

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| users | 用户表 | id, username, hashed_password, phone, follow_count, follower_count |
| content | 内容表（视频/帖子） | id, user_id, title, description, type, category_id, comment_count, like_count, is_deleted, create_time |
| comment | 评论表 | id, content_id, user_id, message, parent_id, like_count, is_deleted |
| follow | 关注关系表 | user_id, followed_user_id |
| content_like | 内容点赞表 | user_id, content_id |
| comment_like | 评论点赞表 | user_id, comment_id |
| content_media | 内容媒体表 | content_id, url, media_type(1=视频,2=图片,3=封面), sort |
| coupon | 优惠券表 | id, title, stock, begin_time, end_time |
| coupon_order | 优惠券领取表 | coupon_id, user_id, coupon_code（唯一索引） |

**注意**：ContentDao 使用了 MySQL 全文索引 `MATCH(title, description) AGAINST (? IN NATURAL LANGUAGE MODE)`

### 6.3 Redis 配置

配置硬编码在 `MyRedisPool.java` 中：
- **地址**: localhost:6379
- **最大连接数**: 50，最大空闲: 10，最小空闲: 5

**Redis Key 设计**：
| Key | 类型 | 说明 |
|-----|------|------|
| `content:like:{contentId}` | Set\<userId\> | 存储给该内容点赞的用户 |
| `comment:like:{commentId}` | Set\<userId\> | 存储给该评论点赞的用户 |

## 九、架构特点总结

### 设计亮点

1. **零框架依赖**：完全不使用 Spring/Spring Boot/MyBatis，所有基础设施手工实现
2. **手写 IoC 容器**：实现了类扫描、拓扑排序、依赖注入、生命周期管理
3. **原生 JDBC**：手写连接池、手动事务管理
4. **多级缓存**：内存缓存 + Redis 缓存，带定时刷新和实时同步
5. **JWT 认证**：无状态 Token 认证，通过 Filter 链实现
6. **RESTful 风格 API**：JSON 响应，统一错误码体系

### 已实现的业务功能

- 用户注册/登录
- 修改密码/用户名/手机号
- 发布视频/帖子
- 内容推荐
- 关键词搜索（MySQL 全文索引）
- 关注/取关
- 内容/评论点赞
- 评论系统（树形结构）
- 优惠券抢购
- 个人主页

### 技术栈总结

| 层面 | 技术选型 |
|------|----------|
| 后端框架 | 纯 Servlet + 手写 IoC |
| 数据库访问 | 原生 JDBC + 手写连接池 |
| 缓存 | Redis（Jedis） |
| 认证 | JWT |
| 密码加密 | BCrypt（Spring Security Crypto） |
| JSON 处理 | Jackson |
| 前端 | 原生 HTML/CSS/JavaScript |
| 构建工具 | Maven |
| 部署 | Tomcat（war 包） |
