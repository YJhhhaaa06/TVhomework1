# .docs 文档索引（唯一入口导航）

> AGENTS.md 只指向本文件。开始任何任务前先读本文件，再按"何时读"选择文档。
> 原则：常青启动必读；说明书按需读；archive/ 历史存档勿读（追踪可追溯）；temp/ 临时文档勿读（可删）。
> 文档可能有滞后性，对架构和业务流程的总结供参考用，以实际代码为准。

## 目录结构

```
.docs/
├── INDEX.md          ← 本文件（唯一入口）
├── 常青/             ← 启动必读，随代码更新
├── 目标与任务/        ← 当前目标与任务（暂空，未来放这里）
├── 说明书/           ← 按需读的参考手册
├── archive/          ← 历史存档（勿读，追踪可追溯，结构与顶层一致）
└── temp/             ← 临时文档（勿读，可随时删除，永不追踪）
```

## 启动必读（常青/）

| 文档 | 一句话 | 何时更新 |
|------|--------|---------|
| 常青/CURRENT_ARCHITECTURE.md | 系统架构地图（技术栈/分层/模块） | 每次架构改动 |
| 常青/BUSINESS_FLOW.md | 业务流程与权限矩阵（偏长，按目录查阅） | 每次业务改动 |

> 提示：常青文档按**章节**按需阅读，不必全文加载。例如：改优惠券逻辑读 BUSINESS_FLOW 第五节；查 API 清单读 CURRENT_ARCHITECTURE 第七节；查包/类结构读其第四节。
