# .docs 文档索引（唯一入口导航）

> AGENTS.md 只指向本文件。开始任何任务前先读本文件，再按"何时读"选择文档。
> 原则：常青启动必读；说明书按需读；archive/ 历史存档勿读（追踪可追溯）；temp/ 临时文档勿读（可删）。
> 文档可能有滞后性，对架构和业务流程的总结供参考用，以实际代码为准。

## 目录结构

```
.docs/
├── INDEX.md          ← 本文件（唯一入口）
├── 常青/             ← 启动必读，随代码更新
├── 目标与任务/        ← 当前目标与任务（暂空，未来放这里）
├── 说明书/           ← 按需读的参考手册

└── temp/             ← 临时文档（勿读，可随时删除，永不追踪）
```
